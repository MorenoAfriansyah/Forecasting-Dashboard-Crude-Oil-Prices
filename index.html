WTI Oil Price Forecast Dashboard

This project presents an interactive forecasting dashboard for WTI crude oil prices using an advanced deep learning approach based on Long Short-Term Memory (LSTM) with Attention Mechanism.

Methodology

  • Time series forecasting using LSTM with an attention mechanism
  • Multivariate inputs: WTI closing prices, US Dollar Index (USDX), and Geopolitical Risk Daily (GPRD) index
  • Feature selection based on ablation study results
  • Train–validation–test data splitting
  • Model evaluation using Mean Absolute Percentage Error (MAPE)
